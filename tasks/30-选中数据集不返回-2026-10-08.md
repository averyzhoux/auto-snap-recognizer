# 30 · 选中数据集后不自动退回取景页

| | |
|---|---|
| **日期** | 2026-10-08 |
| **状态** | ✅ 真机点按验证 |
| **涉及文件** | `MainActivity.kt` |

## 之前

数据集列表里点一行（选为「使用中」），`switchDataset(meta)` 之后紧跟一句
`screen = Screen.Camera`，页面立刻弹回取景页。

## 现在

只 `switchDataset(meta)`，**留在列表页**。

```
onSelect = { meta ->
    // ★ 选完不自动退回取景页：切换只是把「使用中」挪个位置，
    //   留在列表里才能一眼看见换成功没有，也方便接着编辑/再换。
    switchDataset(meta)
}
```

## 为什么

「切换数据集」和「回取景页拍照」是两件事，之前被绑成一步：

- 选错了没法当场改，得重新点顶部入口进来一次
- 换完后**看不到反馈**——「✓ 使用中」刚挪过去，页面已经没了，
  只能靠顶部那个胶囊里的表格名去猜，而那正是容易看漏的地方
- 连换几个表格时，进进出出特别烦

现在切完就停在原地，「✓ 使用中」直接挪到新选的那行，一眼可见。
要回取景页照旧点左上角「‹ 返回」或按系统返回键。

识别引擎和帧缓存的刷新还是由 `switchDataset` 负责，没有变化。

## 验证

真机：进入数据集页后连点四行（`baomazhan` → `bxxxxalance-2.html` → `baomazhan`
→ `示例数据集`），logcat 里四条 `switched to dataset …` 连贯出现，
页面**没有退回取景页**；返回取景页后顶部显示 `示例数据集 20 ›`，与最后一次选择一致。
