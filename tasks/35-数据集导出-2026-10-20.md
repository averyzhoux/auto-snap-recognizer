## 一、文件形式

**第一列标记、第二列词条、剩下的都是别名**：

```
标记,词条,别名1,别名2
✓,Manufacturer,Mfg,Maker
,Model,Model No
,Warranty
```

- 列含义固定：第 1 列标记（`✓` 或空）、第 2 列词条、第 3 列起全部别名
- 别名全部导出，不再丢失；各条别名个数不同，所以行长度可以不同
- 字段含逗号 / 引号 / 换行时才加双引号
- 行尾 `\r\n`

## 一之二、命中结果的显示

需求演进：括号 → 一行小字 → 不换行 → **最终：换行**。

`ResultPanel.kt` 的 `MatchRow` 为两行：

```
✓  Mfg                                        [确认框]
   Manufacturer · 包含
```

- 第一行：识别到的原文
- 第二行小字（`labelSmall`）：正式名 + 命中说明（` · 包含` / ` · 近似 83%`）
- 去掉箭头 `→` 和括号；两段都是单行 + 省略号，行高固定

### 别名命中时补上实际写法

需求：命中靠别名时，显示为 `正式名 · 别名`。数据来自已有的 `LineMatch.matchedOn`
（相册 JSON 也存了这个字段，历史快照同样生效）。

| 情况 | 第二行 |
|---|---|
| 靠正式名命中 | `Manufacturer · 包含` |
| 靠别名命中 | `Manufacturer · Mfg · 包含` |
| 靠别名且完全相同 | `Manufacturer · Mfg` |

- 分隔统一 ` · `（`MatchColors.matchedAliasText()` 生成别名段）
- `matchedOn` 与正式名忽略大小写相同时不重复显示
- **截断优先级**：第二行拆成「正式名（`weight(1f, fill = false)`）+ ` · 别名 · 说明`（不压缩）」。
  Row 先测非 weight 子项，所以窄屏上别名与说明先占位，正式名让位并被省略号截断。
- 相册纵览卡片的 `CardLine` 同步：`note` 传 `正式名 + 别名段`，去掉原来的 `→ ` 前缀；
  相册详情复用 `MatchRow`，自动生效。

数据集编辑页**未改**：正式名和别名本来就是两个独立 `Text` 控件（控件分隔），
不需要再用括号拼接。


## 二、为什么不用「另存为」选择器定默认目录

`ActivityResultContracts.CreateDocument` 只能给定**文件名**，不能指定初始目录；
`EXTRA_INITIAL_URI`（API 26+）只是建议，多数第三方文件管理器会忽略。
所以固定落点只能由应用自己写。

SAF 分支保留为 API 29 以下的回退路径（见第三节）。

## 三、写入方式：`MediaStore.Downloads`

新增 `DatasetExporter.kt`：

| 决定 | 原因 |
|---|---|
| `MediaStore.Downloads` + `RELATIVE_PATH` | Android 10+ 写公共目录的官方通道，**不需要权限** |
| `RELATIVE_PATH = "Download/识鉴相机"` | 目录不存在时系统自动创建；中文目录名对 MediaStore 无影响 |
| `IS_PENDING=1` → 写完置 0 | 写入期间对其他应用不可见，避免读到半截文件 |
| 失败时 `delete(uri)` | 不留 0 字节空壳 |
| 自己算重名 `a.csv` → `a (2).csv` | MediaStore 各 ROM 同名行为不一致 |
| `MIME_TYPE = text/csv` | 文件管理器按类型识别 |

导出成功后 Toast 提示：`已导出到 下载/识鉴相机/xxx.csv`。

### API 24–28 回退

`minSdk = 24`，但 `MediaStore.Downloads` 是 API 29 才有的分卷：

- 29+：直写固定目录
- 24–28：退回系统「另存为」选择器

**没有新增任何权限。**

## 四、导入兼容（`DatasetParser`）

| 输入 | 结果 |
|---|---|
| `标记,词条` 表头 | 跳过（首字段是 标记/marked/mark/已识别 + 第二字段是 词条/名称/name/word） |
| `词条,标记`（旧两列表头） | 跳过（保留兼容） |
| `✓,Manufacturer,Mfg,Maker` | 新格式：名称 Manufacturer，别名 Mfg / Maker，已标记 |
| `,Model,Model No` | 新格式：名称 Model，别名 Model No，未标记 |
| `Model,✓` | 名称 Model，已标记 |
| `Model,` | 名称 Model，未标记 |
| `Model,Mfg`（旧两列文件） | 名称 Model，别名 Mfg（第二列不是 ✓ 就当别名） |

| `Model,marked=yes` | 当作别名 `marked=yes`，宁可多一个别名也不吞数据 |

对勾认 `✓` / `✔` / `√` 三种码位（输入法 / Excel 可能给不同的）。
