# 06 · 小米相机风格 UI 重构

| | |
|---|---|
| **日期** | 2026-10-07 |
| **状态** | ✅ 已完成 |
| **涉及文件** | `MainActivity.kt` |

## 目标

> 需求原话：「优化一下界面，把按钮都弄成小米的相机的 ui 样式。自动还是手动那个按钮弄成单选即可，同时让这个 app 下的屏幕常量（常亮）」
> 补充：「把切换按钮，变成和左侧缩略图对称的位置的单选切换而不是两个按钮进行切换」

## 做了什么

- 整屏取景，控件浮在画面上（不再有独立取景框）
- 顶部状态胶囊
- 底部一行三段：**左缩略图 / 中快门 / 右模式切换**（左右对称，快门居中）
- 快门做成**白色圆环 + 白色内圆**，识别中内圆变方形 + 转圈
- 模式切换从「两个文字按钮」改成**右下角一个圆形按钮**，点一下在自动/手动间切换
- 选中色统一成小米黄 `#FFC800`（模式切换、命中行、结果计数都用它）

## 关键决策

- **屏幕常亮用 `FLAG_KEEP_SCREEN_ON`，不用 `WakeLock`**：不需要 `WAKE_LOCK` 权限、页面退出自动失效、不会漏电。
- 结果面板把**命中的行排到最前**（`sortedByDescending { it.isHit }`，稳定排序），否则一堆未命中的噪声会把结果淹掉。

## 踩坑

1. **快门按钮尺寸 bug**：`.size(76.dp)` 后面又加了 `padding`，导致圆环被撑到 76dp 而父容器被压到 60dp，圆环被裁掉且不在正位。去掉多余的 padding 即可。
2. **结果面板高度必须封顶**。不封顶时识别行数一多，整个 `Column` 超过一屏，顶部状态栏被挤出屏幕。改成 `heightIn(max = ...)` + 内部滚动。
3. 布局用固定 `padding(top = 150.dp)` 猜位置很脆，换成纵向 `Column` 让控件自然堆叠。

## 验证

截图确认：黄色「自动」圆钮在右下、快门居中、缩略图在左下、状态胶囊正常。
