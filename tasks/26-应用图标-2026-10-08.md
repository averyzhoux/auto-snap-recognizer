## 这张图的特殊之处

`icon.png`（1303×1303 RGBA）**中间是真的透明洞**——蓝色光圈 + 洞里悬着一个对勾。
在多数看图器里它看着像「白圆盘 + 对勾」，那是因为看图器拿白底透出来了，
把 alpha 通道打出来才看得清：

```
................oooo#######oooo.................
.............oo#################ooo.............
.#### (蓝色光圈) ####................####
.##################o....o###o.....o############.   ← 洞里悬着对勾
.#### (蓝色光圈) ####................####
```

所以「中间的透明区域要保留」是字面意思，alpha 通道不能丢。

## 做法：平面图标 + 裁到内容外接框

`tools/make_icons.py`（纯 PIL，用 `/usr/bin/python3` 跑）：

1. **裁到 alpha 外接框**（1303 → 1290），让圆盘占满整个画布——平面图标能做的最大尺寸
2. 缩出 48 / 72 / 96 / 144 / 192 五组 `ic_launcher.png` + `ic_launcher_round.png`
3. 删掉模板自带的 `mipmap-anydpi-v26/` 和 10 个 `.webp`
   （不删的话 API 26+ 根本不看位图；同名 `.webp` + `.png` 还会资源冲突）

### ★ 缩放的坑：必须按预乘 alpha 平均

全透明像素的 RGB 是**残留值**（洞里淡黄 `(254,252,193)`、角上灰蓝 `(57,74,81)`）。
直接缩会把它们混进边缘，在蓝圈和洞的边界糊出一圈脏色。
脚本里先 `ImageChops.multiply(band, alpha)` 预乘、缩完再按 `v*255/alpha` 还原。

## 试过但放弃的路：自适应图标

自适应图标能让图标**铺满整块 tile**，试了一版（`mipmap-anydpi-v26/` +
`drawable-*/ic_launcher_foreground.png` + 透明背景），真机上确实铺满了，但：

- 自适应图标只保证中间 **72/108** 可见，外圈会被遮罩切掉——**这张图的外圈正好是那道深蓝描边，切掉就不是原图了**
- 要保住外圈就得把内容缩进 72/108 安全区，那时候渲染出来又只有 tile 的 ~67%，和平面图标一样小，白折腾

所以回到平面图标。

## 实测：平面图标的尺寸天花板

真机桌面横向对比（左 = Recognizer，中/右 = 原生图标）：

**我们的圆盘约为原生图标 tile 的 75~80%，且周围没有垫底。**

原因是 Android 8+ 的启动器对**没有自适应图标的 app** 会做 legacy 处理：
把平面图缩小、垫一块底。这是启动器行为，**改源图大小无法突破**——
已经把圆盘从占画布 97% 裁到 100%，实测几乎没有变化（0.72 → 0.74）。

好消息是**洞保住了**：桌面上洞里透出的是壁纸（那张图上是深色车身），
不是被填成白色或黑色。（之前在「应用信息」页看到洞里是纯黑，那是那个页面自己的深色底，
不是图标被填了色。）

## 备注

- `icon.png` 留在仓库根目录，**没删**；换图后重跑 `tools/make_icons.py` 即可
- 想换成「铺满但是外圈被切」的观感，就把自适应那套加回来
  （背景用 `@android:color/transparent`），代价是丢掉深蓝描边
- 改完图标如果桌面没刷新：`adb shell am force-stop com.miui.home` 会重载；
  **别卸载重装**——一卸载数据集和相册就没了

## 附：中文名「识鉴相机」

`AndroidManifest.xml` 里 `android:label` 本来就引的是 `@string/app_name`，
所以只要加一个中文限定目录，默认的英文名一个字都不用改：

```text
res/values/strings.xml       <string name="app_name">Recognizer</string>   ← 英文（默认）
res/values-zh/strings.xml    <string name="app_name">识鉴相机</string>      ← 中文
```

用 `values-zh` 而不是 `values-zh-rCN`：简繁 / 港澳台一起覆盖，这个 app 的 UI 本来
就只有中文一套，没必要按地区再分。

验证（`aapt2 dump resources`）：

```text
resource 0x7f0d001e string/app_name
  () "Recognizer"
  (zh) "识鉴相机"
```

真机中文环境下「应用信息」页显示的就是 **识鉴相机**，版本号那行不变。
