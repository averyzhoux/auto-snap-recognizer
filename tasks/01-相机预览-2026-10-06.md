# 01 · 接入 CameraX，让相机预览显示在屏幕上

| | |
|---|---|
| **日期** | 2026-10-06 |
| **状态** | ✅ 已完成 |
| **涉及文件** | `gradle/libs.versions.toml`、`app/build.gradle.kts`、`app/src/main/AndroidManifest.xml`、`MainActivity.kt` |

## 目标

把相机预览显示在屏幕上，先不做识别。

## 做了什么

- `libs.versions.toml` 加 `camerax = "1.5.3"` 和 4 个库：`camera-core` / `camera-camera2` / `camera-lifecycle` / `camera-view`
- `app/build.gradle.kts` 引入依赖（走 version catalog，不写死版本）
- `AndroidManifest.xml`：
  - `<uses-permission android:name="android.permission.CAMERA" />`
  - `<uses-feature android:name="android.hardware.camera.any" android:required="false" />`
  - Activity 加 `android:screenOrientation="portrait"`
- `MainActivity.kt` 重写：运行时权限申请 + `CameraPreview` Composable

## 关键决策

- **最小 SDK 保持 24，没有改**。原计划里写「API 36 建议降到 24」，但仓库里已经是 `minSdk = 24`，无需动。
- **锁竖屏**。rotation 是 CameraX + OCR 最大的坑源，先消掉一个变量，等识别跑通再说。
- **权限被拒后给「打开设置」引导**。MIUI/HyperOS 下用户点过一次「拒绝」，系统就不再弹框，不加引导会卡在空白页且无从恢复。

## 踩坑

1. `AndroidView` 里必须**只创建一次** `PreviewView`（`remember` + 空的 `update`）。在 `factory` 里 new 一个的话，重组时相机会反复重绑、闪黑屏。
2. `onDispose` 里必须 `unbindAll()`，否则退出页面后相机没释放，下次进来会报「相机被占用」。
3. `PreviewView.scaleType = FILL_CENTER`，默认缩放方式在部分机型上会拉伸变形。
4. 预览是 Surface 直通，**不需要 Executor**——当时误留了个 `Executors.newSingleThreadExecutor()`，后删除。

## 验证

- logcat：`CameraDevice.onOpened()` → `Preview ... ACTIVE`（camera 0）
- 截图确认实时取景正常渲染
