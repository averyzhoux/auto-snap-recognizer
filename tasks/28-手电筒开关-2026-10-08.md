## 长什么样

取景页左上角、状态文字**左边**一个闪电图案：亮着是小米黄，灭着是半透明白，
点一下开关手电筒。和顶部另外两个控件一样**不加胶囊底色**。

```
⚡  对准目标，等待识别                    示例数据集 20 ›
```

## 三个实现要点

### 1. 闪电是**画的**，不是打 `⚡`

`⚡`（U+26A1）在多数系统上会走**彩色 emoji 字体**，渲染出来是一张黄红渐变的小贴纸，
跟旁边纯文字的观感完全不搭；而且字体里有没有它也没法保证（`⌃` 那次就吃过亏）。
所以用一个 24×24 视口、全部直线段的 `Path` 自绘。

### 2. 状态**跟着相机走**，不是自己记

```kotlin
// 相机的实际手电筒状态 → 图标状态
DisposableEffect(camera) {
    val observer = Observer<Int> { torchOn = it == TorchState.ON }
    cam.cameraInfo.torchState.observe(lifecycleOwner, observer)
    onDispose { cam.cameraInfo.torchState.removeObserver(observer) }
}
```

一开始想用 `var torchOn` 自己记、点的时候翻转。有个说不上来的毛病：
**把 App 切到后台时相机被关掉、手电筒跟着灭，但自己记的变量还停在「开」**，
回来就是「图标亮着、灯是灭的」。

改成观察 `CameraInfo.torchState` 之后，图标永远等于相机的真实状态。
`enableTorch()` 是异步的，所以点的时候**只发命令、不直接改 `torchOn`**，由观察回填。

### 3. 间距：闪电左右必须一样宽

第一版直接在状态文字前面放了个按钮，结果：

```
闪电墨迹   30.2 .. 41.8dp
状态文字   从 56.6dp 开始
→ 左边 30.2dp，右边只有 14.8dp
```

因为**闪电的图形在自己的 40dp 触摸区里是居中的**（左右各垫 10dp），而右边紧接着就是文字、
没有间隙。推导一下：

```
屏幕边缘 → 闪电 = 行首内边距(16) + 触摸区内边距(10) + 图案内缩(3.75)
闪电 → 文字     = 间隙      + 触摸区内边距(10) + 图案内缩(3.75)
```

两个式子只差「16 vs 间隙」，所以**让间隙等于行首内边距就相等**：
`horizontalArrangement = Arrangement.spacedBy(16.dp)`。

实测：左 30.2dp / 右 30.8dp，差 0.6dp。

## 顺带改的接口

`CameraPreview` 多了一个回调：

```kotlin
onCameraReady: (Camera?) -> Unit   // 绑定时给 Camera，解绑时给 null
```

`bindToLifecycle` 本来就返回 `Camera`，`.also(onCameraReady)` 直接接上；
`onDispose` 里回调 `null`——相机没了手电筒也没了，上层正好借这个把图标熄掉。

## 备忘

- 手电筒**只在 `Camera` 非空时可点**（`enabled = camera != null`）。
  相机没绑好时图标是 25% 白，按了也没反应
- 没有「自动关灯」逻辑：切后台时相机被关，灯自然灭，图标也会跟着熄
- 前置摄像头没有手电筒——这里固定用后摄（`DEFAULT_BACK_CAMERA`），没这个问题

## 间距

闪电的左右留白量过两轮：一开始左右各 30dp，太散；砍一半后左右各 16dp。

★ 这个按钮的留白**不能直接按外观算**：触摸区 40dp、图案只有 20dp 且居中，
所以图案左右各垫了 10dp；图案自己又在 20dp 视口里内缩 3.75dp。
也就是说光是按钮本身，左右就各占掉 `10 + 3.75 = 13.75dp`。
想让闪电左右**看起来**一样宽，条件是：

    屏幕边距（外层 Row 的 start padding） = 闪电到状态文字的间隙（内层 spacedBy）

两个值取同一个数就行，这里都是 2dp；实测左右各 16.0 / 16.6dp，
差的 0.6dp 是汉字「对」自身的左边距。
