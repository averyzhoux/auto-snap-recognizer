# 29 · 内置示例数据集也给编辑按钮（但不给删除）

| | |
|---|---|
| **日期** | 2026-10-08 |
| **状态** | ⚠️ 代码完成，装机点选待确认（截图时设备没连上） |
| **涉及文件** | `DatasetScreen.kt`、`DatasetStore.kt` |

## 改了什么

数据集列表里，第一行「示例数据集」（内置、id 0）原来**一个按钮都没有**——
既不能删（条目写死在代码里），也不能进编辑页。现在给它加上「编辑」，
删除仍然只给导入的数据集。

```
示例数据集  内置 ✓ 使用中   编辑
baomazhan  103 项 · UTF-8   编辑  删除
```

## 为什么原来没有

任务 20 做编辑页时，编辑页只有「标记已识别」这一个功能，而标记是要落盘的；
内置数据集的条目写死在 `Dataset.entries` 里，`saveEntries` 直接 `return false`，
所以干脆连按钮都没给。

## 怎么让内置的也能改标记

★ 关键判断：**内置数据集要落盘的不是条目，只是标记。**

如果直接把整份 `000000.entries.json` 写下去，今天能跑，但以后在 `Dataset.kt`
里增删示例项时，老用户目录里那份**过期的文件会把新代码盖住**——
代码里加了 5 条，他那儿还是老的 20 条，而且这种问题不会报错，只会「怎么没生效」。

所以内置数据集单独存一个 `files/datasets/builtin.marks.json`：

```json
["Serial Number", "Rated Voltage"]
```

- 只是一个**名字数组**，条目、别名、顺序一律以代码为准
- 按**名字**而不是下标存：以后在列表中间插一条，老标记不会整体错位
- 名字对不上的标记就自然失效（被删掉的示例项不会复活）

对应 `DatasetStore` 的改动：

| 方法 | 之前 | 现在 |
|---|---|---|
| `entriesOf(0)` | 直接返回 `Dataset.entries` | `builtInEntries()`：读标记套上去 |
| `saveEntries(0, …)` | `return false` | 只把 `marked == true` 的名字写进 `builtin.marks.json` |
| `delete(0)` | 直接 return | **不变**（仍然删不得） |

`DatasetMeta.builtIn` 的注释也跟着改成「不可删除（但可以进编辑页改标记）」。
`DatasetScreen.DatasetRow` 里删掉 `if (!meta.builtIn)` 对编辑按钮的包裹，只留删除。

没有动 `Dataset.kt` 本身——内置条目依然是一行代码写死的常量，改标记不会污染它，
`Dataset.entries` 永远是「出厂状态」。
